Reports @Builder.ObtainVia whose target does not match the call Lombok generates.

Lombok writes the call directly into the generated toBuilder(): this.method() with no arguments, or Type.method(this) when isStatic = true. If the named member is missing or has the wrong signature, the generated code does not compile — but that code has no source, so the editor stays silent until you run a build.

Lombok itself only checks the syntax of the annotation (naming both field and method, or isStatic without method), never the signature.
